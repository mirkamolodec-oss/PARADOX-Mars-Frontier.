# PARADOX: Mars Frontier

**Команда:** AZhoS  
**Трек:** Gambit Hackathon 2026 — AUTOMATE IT!  
**Жанр:** 2D survival / exploration / base building / automation  
**Платформа:** Web / HTML5 (локальный запуск в современном браузере)  
**Технологии:** HTML5 Canvas 2D, JavaScript, CSS, LocalStorage, Web Audio через HTMLAudioElement.

## О проекте

PARADOX: Mars Frontier — 2D-игра о выживании после аварийной посадки на Марсе. Игрок исследует поверхность, добывает ресурсы, создаёт предметы, строит базу и восстанавливает энергосистему, чтобы подготовить ракету к возвращению на Землю.

Тема AUTOMATE IT! раскрывается через энергосеть и производственные объекты: игрок размещает солнечные панели, соединяет объекты медными проводами, устанавливает автоматические буры и организует снабжение базы. Автоматизированные установки продолжают работать после размещения и подключения; игрок может расширять и улучшать систему.

## Цель и игровой цикл

1. Исследовать окрестности и собирать ресурсы.
2. Создавать материалы и необходимые предметы.
3. Построить жилой купол и инфраструктуру.
4. Установить солнечные панели и соединить энергосеть проводами.
5. Подключить автоматические установки для добычи ресурсов.
6. Отремонтировать ракету, обеспечить её топливом и зарядом пусковой системы.
7. Запустить ракету и завершить экспедицию.

**Условие победы:** отремонтировать шаттл, обеспечить требуемый запас топлива и заряд пусковой системы, затем выполнить запуск. При критическом состоянии персонаж может погибнуть и возродиться; отдельный экран поражения не реализован.

## Запуск игры

### Локальный запуск

1. Скачайте ZIP-архив проекта.
2. Распакуйте его полностью в одну папку.
3. Не перемещайте HTML-файл отдельно от каталога `audio/`.
4. Откройте `PARADOX_Mars_Frontier_Victory_AZhoS_Audio.html` в актуальном Chrome или Firefox.
5. Нажмите «Начать экспедицию» или «Продолжить».

Игра не требует установки Node.js или Godot для обычного запуска HTML-билда. Интернет для игрового процесса не предполагается.

### Сборка / исходники

Игра реализована как автономная HTML5 Canvas-программа. Для разработки достаточно текстового редактора и современного браузера. Отдельная команда сборки не требуется: запускается HTML-файл с расположенной рядом папкой `audio/`.

Сохранение игрового состояния и пользовательских настроек выполняется локально через `localStorage` браузера. Игра не требует учётной записи. Перед передачей компьютера другому игроку можно начать новую игру; локальное сохранение относится к текущему браузерному профилю.

## Производительность и тестирование

Проект использует Canvas 2D и локальные аудиофайлы. Фактический FPS, время загрузки и стабильность зависят от устройства и браузера. В этом пакете выполнена статическая проверка JavaScript и целостности ZIP. Попытка запустить Chromium в тестовой среде не завершилась, поэтому фактический FPS и runtime-стабильность здесь не измерены. Это не заменяет 10-минутный тест на целевом ноутбуке Windows 10/11 с 8 ГБ RAM и встроенной графикой. Перед оценкой рекомендуется проверить FPS, загрузку, звук и полный игровой цикл на машине, близкой к тестовому окружению хакатона.

## Известные ограничения

- Отдельный экран поражения отсутствует; предусмотрено возрождение персонажа.
- Кнопка «Выход» сохраняет прогресс и предлагает закрыть окно. Браузер может запретить JavaScript закрывать вкладку/окно, если оно не было открыто скриптом; в таком случае окно закрывается пользователем вручную.
- Точное соответствие короткого core loop 3–5 минут и обучение за 60 секунд требует проверки живым игроком.
